# Книжный рекомендательный сервис

## Результаты

Часть оценок каждого читателя случайно отложили в test (seed = 42). Топ-10 проверили на 1000 читателях, у которых хотя бы одна тестовая книга получила 4 или 5. Книги, которые читатель уже оценил в train, в его рекомендации не попадают.

| Модель | Precision@10 | Recall@10 | nDCG@10 |
|---|---:|---:|---:|
| Content-Based | 0,04330 | 0,17158 | 0,13145 |
| Item-Based CF | 0,00210 | 0,01700 | 0,00689 |
| Popularity | 0,00080 | 0,00316 | 0,00239 |
| SVD | 0,00090 | 0,00325 | 0,00208 |

Лучше всего в топ-10 сработала контентная модель. Для SVD отдельно проверили, насколько точно она предсказывает оценки. На всех 190 975 тестовых оценках у неё RMSE **0,84160**, а у прогноза по средней оценке книги — **0,94834**. В коде для разложения используется `TruncatedSVD` из scikit-learn.
